# Changelog

## 1.1.0 – 2026-10-03
- **Shalva for Copilot (full):** autonomous Copilot Studio agent for Outlook – filing to client folders with one-line summaries, priority categories and flags, drafts (in-thread via agent flow), focus blocks, drafting sessions, learning from drafts, SharePoint dashboard and summary email.
- **Shalva Lite:** platform-neutral version for ChatGPT, Gemini and Claude Projects.
- Bilingual guides (English / Hebrew) for every platform: install, setup, daily use, update, uninstall, troubleshooting.
- Screenshots with dummy data for every platform in both languages.

## 1.0.0 – 2026-10-03
- First release (Claude): interview in the language of your choice, style and labeling learning, daily triage, drafts, focus blocks, drafting sessions for complex emails, learning from drafts, live dashboard and summary email.
- Every email filed with no action gets a one-line summary, with a searchable Archive tab on the dashboard.
